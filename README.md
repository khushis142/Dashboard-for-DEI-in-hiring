# Dashboard-for-DEI-in-hiring
Dashboard for DEI in hiring using Python and Streamlit

Problem:
Poor gender ratio: AlwaysFirst has a men to women ratio of 73:27. They are also struggling with  diversity candidate ratio.
Lack of supporting data: They lack the necessary data to drive progress in hiring gender diverse talent.

Goal:
Improve diversity ratio: AlwaysFirst aims to improve their diversity ratio by hiring more gender diverse talent.

Required Solution:
Intelligent data analysis: They seek an intelligent approach to create and analyze data for better insights.
BuildTogether: A dashboard to insure that managers stay accountable for reach corporate D&I goals.

Tools and technologies: : Python, Streamlit, Scikit-learn, MySQL

Note: Use database_final.txt to create database in mysql.
Use ws.py for webscraping. Selenium and chromedriver_win32 required.
